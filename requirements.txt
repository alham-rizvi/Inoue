# API backend (api/main.py), needed for `uvicorn api.main:app` - the browser
# extension and external MCP-style clients talk to it. Pinned in exactly one
# place (requirements-api.txt) so a CLI-only environment can install just the
# block above and skip the include line below:
#     pip install -r requirements-api.txt        # or: pip install -e ".[api]"
#
# The include keeps the default install, CI and the Dockerfile working: CI runs
# `pip install -r requirements.txt`, and without the API packages
# tests/test_api.py raises unittest.SkipTest, which would silently drop the
# whole API test class from the matrix instead of failing.
-r requirements-api.txt

# Shodan-style mmh3 favicon hashing (core/favicon.py). Only adds the mmh3 value
# to the favicon report - md5 hashing works fine without it, which is why it is
# not installed by default:
#     pip install mmh3>=4.0                      # or: pip install -e ".[hashing]"
#
# MCP server (mcp_server.py):
#     pip install mcp>=1.0                       # or: pip install -e ".[mcp]"
#
# Opt-in recon tooling. Each of these is imported behind a try/except
# ImportError in the module it serves, so the CLI and everything above works
# without them - install only when you want the extra signal:
#     pip install wafw00f>=2.4 pydnsbl>=1.1 pyasn>=1.6
#                                                # or: pip install -e ".[recon]"
#
#   wafw00f - active WAF fingerprinting. NOTE the import path is
#             `from wafw00f.main import WAFW00F`, not `from wafw00f import WAFW00F`.
#   pydnsbl - extra DNS blocklist sources for core/reputation.py.
#   pyasn   - optional offline ASN cross-check for core/asn_intel.py; it only
#             runs when a local ipasn database file is found.
#
# Deliberately NOT added: checkdmarc (Apache-2.0). Its `cryptography>=50.0.0`
# pin breaks pyOpenSSL 25.1.0 and `import checkdmarc` fails outright in this
# environment, so email authentication is checked with dnspython instead.
